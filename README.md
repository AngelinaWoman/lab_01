# Лабораторная работа №1

Консольный калькулятор и конвертер величин на Python.

## Возможности

**Калькулятор**
- целые и вещественные числа;
- операции `+`, `-`, `*`, `/` с учётом приоритета;
- унарные `+` и `-` перед числом;
- пробелы между токенами игнорируются;
- вычисление через обратную польскую нотацию (алгоритм «Шунтирующий двор»).

**Конвертер**
- длина: `mm`, `cm`, `m`, `km`;
- масса: `g`, `kg`;
- температура: `c`, `f`, `k`;
- регистр единиц не учитывается;
- конвертация между разными группами запрещена;
- температура ниже абсолютного нуля запрещена.

## Использование

```bash
python -m toolkit calc "EXPRESSION"
python -m toolkit convert VALUE --from UNIT --to UNIT
python -m toolkit --help
```

Примеры:

```text
$ python -m toolkit calc "-5 + 2 * -3"
-11.0

$ python -m toolkit convert 100 --from c --to f
212.0
```


## Ошибки

При ошибке сообщение выводится в `stderr`, программа завершается с кодом `2`.
Успешная команда завершается с кодом `0`.

**Возможные сообщения об ошибках**
- Пустое выражение;
- Недопустимый символ: ...;
- Пропущен операнд;
- Пропущен оператор;
- Два оператора подряд;
- Неверное числовое значение: ...;
- Деление на ноль
- Неизвестная единица;
- Несовместимые единицы;
- Температура ниже абсолютного нуля.

Пример:

```text
$ python -m toolkit convert 1 --from m --to kg
Ошибка: Несовместимые единицы
```

## Как устроен калькулятор

1. `tokenize` разбивает строку на токены `NUMBER` и `OPERATOR`. Знак `+` или `-` в начале выражения
   или после оператора считается частью числа.
2. `validate_tokens` проверяет порядок токенов (пустое выражение, два числа или два оператора подряд,
   выражение, начинающееся или заканчивающееся оператором).
3. `to_rpn` переводит инфиксную запись в обратную польскую нотацию с учётом приоритетов.
4. `evaluate_rpn` вычисляет результат с помощью стека.
